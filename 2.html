Estrutura e Sintaxe do CSS

1. O que é uma Regra CSS?

Uma regra CSS é composta por três partes:

  • Seletor — indica qual elemento HTML será estilizado
  • Propriedade — o que será modificado (cor, tamanho, etc.)
  • Valor — o valor aplicado à propriedade

2. Pseudo Classe — :hover

Aplica estilo quando o mouse passa sobre o elemento.

3. Pseudo Elemento — ::before

Insere conteúdo visual antes do elemento, sem mudar o HTML.
