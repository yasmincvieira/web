O que é JavaScript?

Motivação
O JavaScript foi criado pela Netscape em 1995 para tornar a web interativa. A empresa precisava de uma linguagem de script leve que rodasse no navegador para tarefas simples, como validar formulários e criar animações básicas, substituindo as páginas estáticas da época que dependiam exclusivamente do servidor.

Diferença entre execução no navegador de no servidor
A principal diferença está no ambiente e no propósito: o navegador executa o JavaScript no lado do cliente (front-end) para criar interfaces e interações dinâmicas, enquanto o servidor processa regras de negócio no backend, lida com bancos de dados e gerencia arquivos.

Sandbox
A sandbox no navegador é um ambiente de execução isolado e seguro. Ele restringe o que o código JavaScript de um site pode fazer, impedindo que ele acesse arquivos do sistema, modifique o navegador ou interaja com dados de outras abas sem permissão.

Objetos Globais
Objetos globais em JavaScript fornecem funções e dados disponíveis em qualquer lugar do seu código.
  • Document
    • O objeto document é o ponto de entrada principal para a árvore do DOM (Document Object Model). Ele representa a estrutura da página HTML e permite que você selecione, altere, crie ou remova elementos diretamente na tela.
    • Uso comum: document. getElementById('meu-elemento') ou document.querySelector('p') para manipular tags HTML.
    • Acesso: Ele é uma propriedade do objeto global (window.document), mas geralmente é chamado de forma direta.
  • Console
    • O objeto console fornece acesso ao console de depuração do ambiente. É a principal ferramenta para verificar o estado de variáveis e testar lógicas.
    • Uso comum: console.log('Mensagem de teste'), console.error() e console.table().
    • Acesso: Disponível diretamente como console.
  • Alert
    • A função alert() é um método do objeto global que exibe uma caixa de diálogo pop-up no navegador com uma mensagem e um botão de "OK". Geralmente é utilizada para avisos simples, pois pausa a execução do script até que o usuário interaja.
    • Uso comum: alert('Ação concluída com sucesso!');
    • Acesso: Funciona chamando window.alert() ou simplesmente alert().
