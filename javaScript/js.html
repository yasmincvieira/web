Como declarar variáveis

Usamos let ou var para declarar variáveis

var nome; //cria uma variável global com identificador nome
let idade; //cria uma variável local com idenificador idade

Tratamentos em Eventos em JavaScript

Tratamos evento js usando addEventListener que vincula uma função a um evento específico do DOM.

Exemplo:

document.addEventListener('click', function(){ console.log('Clique detectado!') })

Eventos comuns disponiveis nos Navegadores

  • click - evento de clique
  • mouseover - evento de mouse sobre o elemento
  • mouseout - eveneto de maouse fora do elemento
  • mouseenter - eveneto de entrando no elemento
  • keypress - evento de tecla pressionado
  • keydown - evento de tecla pressionada
  • keyup - evento de tecla solta
  • submit - eveno de envio de formulário da tag form
  • DOMContentLoaded - evento disparado quando o documento HTML é completamente carregado e parseado
  • change - evento disparado quando o valor de um elemento de formulário é alterado
