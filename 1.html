HTML

O que é HTML?

HTML (Linguagem de Marcação de HiperTexto) é uma linguagem de marcação para estruturar e construir páginas na web. Com o HTML consegue-se criar uma página com elementos como títulos, parágrafos, links, imagens, etc. O HTML não é uma linguagem de programação e sim de marcação para estruturas de sites.

Qual o papel dele na Web?

A função do HTML é unicamente utilizada para estruturar conteúdo de páginas web. Ou seja, não cabe a ele definir carcatrpisticas visuais e comportamentos, pois foi criado e deve ser feito utilizando CSS e JavaScript.

Ordem cronológica

  • 1989-1990: A Web (WWW): Tim Berners-Lee, no CERN, cria o conceito de hipertexto, o protocolo HTTP e o primeiro navegador.
  • 1991: HTML: A primeira linguagem de marcação é introduzida para estruturar os documentos na web.
  • 1996: CSS: O W3C publica a primeira recomendação do CSS (Cascading Style Sheets) para separar o design do conteúdo.
